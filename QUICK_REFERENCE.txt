   Response: {"success": true, "message": "Password reset"}

1. User submits email/username  → POST /api/auth/forgot-password/
2. Reset token generated        → Using Django's default_token_generator
3. Email sent with reset link   → Via console (dev) or SMTP (prod)
4. User clicks reset link       → GET /reset-password/<uid>/<token>/
5. User enters new password     → POST /api/auth/reset-password/
6. Token validated              → Must match user & not expired
7. Password updated in DB       → Hashed with PBKDF2
8. User can login               → With new credentials

Email not appearing in console?
  • Verify EMAIL_BACKEND is 'console' in settings.py
  • Check Django dev server is running in correct terminal
  • Look at dev server console, not separate window
  • Refresh page and try again

Token invalid error?
  • Tokens expire after 24 hours
  • Generate new token by requesting password reset again
  • Use token immediately after generation

Password reset fails?
  • Verify both password fields match exactly
  • Check UID and token from URL are correct
  • Ensure token hasn't expired

Can't login with new password?
  • Verify password was entered correctly both times
  • Password is case-sensitive
  • Try resetting password again with new token
